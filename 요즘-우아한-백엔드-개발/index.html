요즘 우아한 백엔드 개발

우아한형제들, 『요즘 우아한 백엔드 개발』 — 4장부터 11장까지 두 장씩 묶은 학습 문서. 사례마다 무엇이 문제였고 무엇을 골랐고 결과가 어땠는지를 먼저 잡고, 책의 설명 · 예시 · 코드를 책의 순서대로 싣는다.

  • 4장 대규모 트래픽의 C++ 시스템 자바로 전환하기 · 5장 카프카 대신 RDB 기반 Task 큐로 해결하기운영 서버 구조 전환 — 그대로 둔 것과 바꾼 것
  • 6장 KafkaConsumer 에 동적 스로틀링 적용하기 · 7장 실시간 마케팅을 위한 PoC 개발기병목 단계와 처리량 조절
  • 8장 Elasticsearch 병렬 테스트를 향한 여정 · 9장 검색 성능 개선을 위한 인덱스 구조와 쿼리 최적화Elasticsearch 테스트 격리와 쿼리 최적화
  • 10장 Server-Sent Events로 실시간 알림 전달하기 · 11장 B마트 OMS의 물류 주문 관리를 통한 출고 최적화SSE 실시간 알림과 OMS 출고 시점 산정
